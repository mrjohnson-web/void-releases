# Void

Installers for Void, a self-hosted, account-free chat and voice app for
Windows. You can host a server for friends or join one, and chat history stays
on your own device.

## Install

1. Open the [latest release](https://github.com/mrjohnson-web/void-releases/releases/latest).
2. Download `Void-Setup-<version>.exe` and run it.
3. Windows warns about an "unknown publisher" because the installer isn't
   code-signed. Click **More info**, then **Run anyway**.

After that, Void updates itself. It downloads new versions in the background
and installs them when you quit.

This repo only holds releases. The app checks it for updates.
